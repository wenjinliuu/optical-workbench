# 本人原通用任务状态筛选 · V0.79

继续 T03.03/M01-F03。本人业务责任仅在 `kind=task` 时可按原任务字段筛选：`blocked` 读取 `lifecycle_status`，`awaiting` 读取 `assignment_status`，`paused` 与 `running` 读取 `execution_status`。这些维度可以重叠，不相加为任务总量，也不把其余十三类业务的不同状态推断成统一状态。

筛选条件 `task_state` 加入当前来源、分页和授权证明。非任务类型携带非 `all` 状态时，服务端明确拒绝；界面保留未查询填写，要求改回通用任务或明确退出任务状态。当前分类入口从任务状态返回全部/其他业务时，按钮明确写出会退出任务状态，不静默改变条件。

本人已指定责任与本岗位未认领候选分别读取；候选的阻塞事实不会触发认领、接收或解除阻塞。原详情办理前后仍重新证明当前来源；接收、开始、暂停、解除阻塞等动作继续只在原任务入口发生，成功后按已应用条件刷新。退出、停用、改岗和迟到响应继续清空私有内容。

本切片不新增表或迁移，不定义专业审批、今日时区、时限或通知规则。单元覆盖四个原字段状态、可重叠状态、同源分页/证明、候选零写、跨店/岗位边界及独立恢复；电脑/手机检查覆盖明确退出、原接收刷新、44px 控件、无溢出与退出迟到清空。精确源全量 CI 与双处发布结果以 `progress.json` 和 `progress-sync.json` 为准，整体验收继续保留。
