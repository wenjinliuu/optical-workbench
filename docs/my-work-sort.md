# 本人原责任日期与更新顺序 · V0.74

继续T03.03。本人原14类责任和本岗位候选的GET /api/my-work[/authorization]新增单值sort=updated|date_asc|date_desc。默认原记录最近更新，负责人原总览/休假交接保持默认原顺序。未知/重复排序选项拒绝，客户端不能提交SQL或任意字段排序。

日期升/降序只采用已保存due的原日期部分（时间型按原UTC日期）。已记录日期先显示，日期未知固定在后；同日按原事件更新倒序，再以原业务类型/ID/行号稳定排序。日期本身没有小时精度的记录不补午夜，也不以联系时间小时先后替代同日原更新顺序。原日期、修订、固定版本与机构/customer保持原值。候选任务均无日期，两种日期顺序保持其原稳定更新顺序，不自动认领或接收。

日期/文字/业务类型筛选及完整数量保持；排序也是来源证明的一部分，跨排序旧页/证明拒绝。105条已记录加未知原任务的完整分页、106条浏览器责任中未知准备尾项已验证，原日期修改后旧来源失效。切换查询后迟到旧排序结果不得恢复旧列表；原任务明确接收后保留手机日期与排序选择，退出/失权清空沿原会话守卫。

只读，不新增日期、优先级、时限、客户、任务、专业或资金事实。schema60，无新表/迁移。8项新增覆盖两向/同日顺序、完整分页/来源、严格排序、候选/过滤、原日期修订、零写与独立恢复；完整验证和双处发布状态以progress.json/progress-sync.json为准。正式营业日、资质/专业审批和整项业务验收继续待完成。
