保存前要求当前准备说明未撤回且有名单处理原说明、当前责任人可用，未知或拒绝不能保存名单；它仍不代表正式授权核验或临床同意。名单原件仅当前准备责任人或本店负责人读取，家长、其他准备员工和外店拒绝。责任移交后旧负责人失去名单权限，原活动元信息仍按本店规则读取。

每版固定当时活动说明、完整本店客户资料版本引用、项目序列/资料行前缀、原CSV摘要和原操作角色/时间。候选与错误按这些不可变引用及保存日期重建，后来项目/姓名/资料/日期变化不换旧建议；删除一个原候选引用也不能让多候选悄变单一候选。全部候选未确认身份，不创建/合并客户、不改档案、预约或产生报告。

编辑器可读取UTF-8文件，保留BOM/CRLF原文本；手工编辑形成明确新文本。当前CSV预检给所见候选/错误和完整错误下载；输入变更移除旧预检。来源变更拒绝保存，保留文件文本、来源、批次和依据，明确重读再核对。旧版更正不静默跳到当前，所见旧修订保存被拒绝，明确重读当前修订后保留CSV再保存新版本。原CSV文本下载为TXT供原件核对，错误/核对明细按CSV下载并处理公式前缀。

API `/api/screening-batches/:project[/context|authorization|:batch]` 共用本原活动范围。GET读取完整批次数及同源分页、批次版本/原名单，`:batch?version=:version`准确读旧版。授权证明在采用迟到响应前重核；版本/根分页绑定本原活动、当前责任和批次。POST明确携带原批次/项目/客户来源、原活动版本、批次修订、CSV及依据。

正向依赖在缓存重放前再次检查，正文读取后重核当前身份/安全修订和事务会话。项目撤回、来源变化或责任移交不能用旧成功缓存绕过；原件/引用/审计和幂等共同回滚。数据库直接写入同样保护当前原活动/责任范围、完整规范原客户版本集合、固定根/编号和连续序列、原时间/不可变。恢复独立核对CSV摘要/解析、完整原客户引用/历史前缀、原活动版本、原角色和数量，不用后来当前姓名代替旧事实。客户跨店移交仍待正式规则，不在本地切片中推测。
