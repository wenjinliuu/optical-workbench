# V0.58 指定本人原时段开放、选择与实际接纳

T08.02第三切片。员工按当前客户明确选有效授权本人、原有效个人训练计划和原训练时段，填写对外说明与独立内部依据后开放。根固定客户、本人、原计划和时段；新版固定采用原计划版本/状态事件、原时段版本/资源引用与起止时间。未向本人开放的其他安排不进入家庭响应；资源、人员、计划临床内容和其他客户信息不公开。

家长明确选原开放版本，保存固定原时段的预约意向和选择引用；事务内原family_request_roots/events与选择一起保存，提交可恢复。满额只提示原排期事实，允许保留意向，不承诺名额。当前本人已有原同一时段/重叠预约或同客户、同原时段有效选择时，给出重复/冲突原因，阻止再次提交；撤回或结束旧意向不会抹去原选择。

前台/负责人读取选择与当前原来源，明确选booked或waiting，填写原安排说明和依据后接纳。原计划/时段版本、当前本人授权/员工和资源、容量及客户重复/冲突在当前来源与同一事务内复核，原schedule_bookings/booking_events只创建一次，并保存不可变接纳关联。正式预约与候补分开；候补不保证名额、不自动转正。原预约后续真实请假/调课沿原排期，最小原事实公开沿V0.57明确办理。选择意向、内部回复、实际接纳和对外事实公开分别保存，不代填回复/批准或送达。

原来源后来改版、暂停、撤权或撤回，阻止新选择/新接纳，旧开放、选择、意向与实际原预约历史保留；新开放版本不替换老选择，也不把旧选择自动改投新时段。固定根不允许更换原计划/时段或接收人，需要明确新根。负向撤回在本人授权已撤销时仍保留员工办理入口。

## API 和页面

- 员工GET `/api/family-offers/customers/:customer/options`：当前本人/计划和原时段有界选项，时段可按同来源取完；本人/计划首100超限明确标记。
- 员工GET `/customers/:customer/source?recipient_id=&plan_id=&slot_id=`：明确选定的当前原来源及守卫原因；不默认选择。
- 员工GET `/customers/:customer`、`/:id?version=N`：同客户原开放及数值旧版本/有界历史；POST根、`/:id/versions`、`/:id/events`：明确开放、空白说明新版及撤回。
- 本人GET `/family/:customer`、`/family/:customer/authorization?expected_source=`：指定本人已开放最小内容，采用响应前复核当前授权/开放/原来源；原容量原因只公开文字和代码，不公开资源/其他客户身份。POST `/:id/select`：选定版本来源+本人标题/说明，原意向和选择原子保存。
- 员工GET `/requests/:request`、`/selections/:selection`：原选择/原意向和正式预约或候补的当前守卫；POST `/selections/:selection/admit`：明确保存真实原预约或候补，已有接纳沿原预约办理。

默认30、最大100，后页要求同来源，未知/重复参数、假审批字段及不合法版本拒绝。正文等待后复核当前身份、安全修订/门店与强制密码，共享事务核对会话。正向当前本人/原来源守卫在幂等缓存返回前检查、实际保存时再次检查，审计失败全部回滚。接纳缓存保留第一次实际接纳，不重复创建；当前授权、原开放或意向无效仍阻止正向重试。

员工入口在客户详情，家长入口在本人预约请假申请；原选择接纳入口在申请详情。选择器全部初始空白，明确核对来源才能保存，新版说明为空白；续读保留输入，固定根的本人/计划/时段禁改。迟到撤权读取清空开放列表/弹窗，退出登录清空新增弹窗；电脑手机均可办理。

## 原生、恢复及虚构展示

schema52新增5表family_offer_roots/versions/events/selections/admissions，总227表。原生检查固定同客户/门店/命名本人、当前计划/时段/资源/员工、连续编号/版本/流水和完整配对、原选择与首次原意向同一时间/本人/期望区间、跨开放根同原时段重复、实际原预约首次事件及当前版本/不可变。选择捕获原排期、开放与意向流水前缀；实际接纳捕获原开放前缀/意向修订/原实际预约事件。恢复按原前缀和固定版本重放，原计划/时段/资源后来变化、撤权和员工角色变化不改旧事实，独立恢复清空会话。

八独立虚构阶段：开放、满额、本人已选择、实际原预约、实际候补、原来源变化、开放撤回、明确新版。独立2客户/2用户、2原有效计划、2资源/8时段/4原预约、8开放根/9版本/1撤回、3本人选择/2实际接纳。重复追加全为零，不复用旧资源，不改变此前虚构或人工来源。
