# 协作接口故障定位 · V0.90

T01.04 / N07 的运行保障修复：本人工作台、团体活动/名单预检/固定批次/逐行关联及建档、员工责任/事实/休假交接接口此前都被记成 `/api/unknown`。现在按明确的静态路由模板记录操作类别，“运行与恢复”分别显示本人工作台、团体筛查与名单、员工责任与交接。

模板仅用于诊断，不参与路由分派或授权。日志中的任务、活动、员工、版本及名单行号替换为固定占位符，查询文字/来源证明、请求正文、Cookie、CSRF、密码及数据库错误不进入日志。非法或未登记路径继续使用匿名未知类别，静态资源不纳入 API 请求计数。

仍只有本店负责人可读取本店运行窗口，故障编号与原响应对应；启动累计、200 请求窗口、最近20故障及中断499只计一次的口径保持。分类不写入业务表，不改schema60、完成来源或历史版本，也不构成正式监控/恢复目标或整体验收。

验证入口：`test/runtime-routes.test.mjs`、`test/foundation.test.mjs`、`npm run test:operations-browser`。新增浏览器流程检查桌面1440×1000、手机390×844、故障名称/编号、脱敏、无横向溢出和退出后的迟到响应清空；GitHub Actions `[browser-operations]` 运行同一浏览器流程。
