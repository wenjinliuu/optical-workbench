# 团体筛查名单导入预检（V0.65）

对应 T08.03 / M17-F01、D、R、A、W6-N1/2、S12。原机构、批次和名单原来源需明确填写。CSV 使用 UTF-8、完整中文模板表头及顺序：名单编号、姓名、出生日期、联系人、电话、名单授权状态、授权来源说明。未知日期/电话保留空列；本地切片单次最大256 KiB、500条，尚不是生产容量承诺。

解析支持BOM、CRLF/LF、引号内逗号/换行及双引号转义，原行号和原始字段保留。空白物理行略过，全空的7列名单仍列为错误，不静默删除。表头、结构性引号错误及超限整份拒绝；列数、姓名/编号/日期/控制字符错误逐行说明，重复编号的每一行都留待核对。名单授权明确未知、有记录、拒绝、已撤回；有记录须说明原依据，缺授权或负向授权不变成已授权名单。

按当前门店原档案精确姓名及已知出生日期生成候选；已知不同日期排除，未知日期不补值，同名多个候选明确多义，单一候选也未确认身份。完整候选数与前20候选分开，名单每页30条完整浏览。没有候选保留待核对，不自动新建档案、合并、关联或覆盖原档案。机构/批次及名单均未保存，不生成报告、专业检查或临床同意。个人报告和机构汇总授权仍待正式流程。

`POST /api/screening-import/preview` 明确传机构/批次/来源、CSV和所见 `expected_source`。本地开发岗位 manager/reception/professional 仅新增 `screening:prepare` 预检权限，家长拒绝；它不代表正式筛查资质或专业批准。服务端限本店，并在读取正文后再次核对当前身份/门店/安全修订、改密要求及原会话，防止等待正文期间撤权。

`GET /api/screening-import/authorization` 读取当前匹配来源；带 `expected_source` 在采用迟到响应前再次核对。来源绑定本店参与匹配的客户字段/资料修订和操作身份，另一店变化不干扰本店；当前原档案变化拒绝旧结果。前端保持输入，明确重读后再次预检；已知岗位失效清空名单与结果。编辑输入立即移除旧结果，退出/迟到响应不恢复名单。本地CSV读取验证UTF-8及字节限额，失败文件不误用旧CSV。结果只在当前浏览器内，没有写入审计、幂等或业务账。

错误下载由服务端随预检生成，含原机构/批次/来源、名单序号与原文件行、原始7列及额外字段、错误/核对代码与说明。CSV引用字段和公式前缀保护，避免表格软件执行输入内容；原字段在预检 `raw_cells` 中保留。候选提醒同样进入下载，不能把无格式错误当作已确认身份。
