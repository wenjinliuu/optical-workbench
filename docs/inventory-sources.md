# V0.43 · 库存业务来源总览

T07.02 和 W5-N3/N4/N5/N6 的读取切片，把同一商品的采购收货、原批质量、供应退供、配镜预留、销售实际出库与原库存累计流水放到一个可核对入口。沿用原门店与商品，六类来源只读取保存过的原记录，不能据此声称完整批次仓位分配已经完成。

## 当前商品数量与原业务来源

库存页每个实物商品增加“查看库存业务来源”。按原单位显示当前可用、预留、隔离以及实物在库总量。核对关系明确列出：原累计可用减实际可用来源销售、原累计预留减实际原单预留来源销售、原累计隔离减实际供应退供交出。供应方收件不再扣库存。当前质量受保护量和未被质量占用的隔离量分别显示，不能用总隔离量绕过原批复检。

采购收货保留固定原采购/供应方资料版本、原商品版本和单位、实际到货/匹配量/超收未匹配量、当前收货资料和已保存批号效期仓位。明确已入账数量、已实际退供及当前原质量保护量独立列示。本批今天的实际在库分配量为 null，页面明确尚未建立完整分配，不能由原采购入账量推定。

原批质量显示原收货/观察、原数量、实际已交出、未退供量、当前受保护隔离量和未交出安排。已放行批次未退供量不称为仍隔离。退供安排显示商业状态、原固定数量、实际交出、供应方已收及已交出待收件量；停止剩余安排和供应方收到不改原实际交出事实。

配镜预留按原事件/商品分组，多条同SKU原行不重复列成多份预留事件，数量保留逐行原来源。当前有效预留减去其实际销售出库；旧释放事件与旧原版本不被当前订单覆盖。销售出库列原单/版本/行、实际数量来源、当时可用/预留/隔离快照和当时库存/销售/退供前缀，旧快照保持。

原累计库存流水显示其当时累计账，明确区别于当前实物投影；固定收货入库或质量库存引用可返回原业务。页面六类卡片可打开原收货、原批复检、退供/收件或原配镜单。读取不新建批次，不补资金、资格、仓位分配或专业结论。

## 范围、分页和恢复

GET /api/inventory/products/:id/sources，kind=all/receipt/quality/supplier_return/reservation/dispatch/stock，limit 1..100（默认30），offset 0..1000000。负责人/前台/专业人员须当前库存和收货读取权限；家长拒绝、跨店404、停用或撤销会话立即失效；服务类不记实物来源。仅GET，未知查询字段和无效筛选拒绝。

六类完整数量与实际分页独立，稳定排序 created_at DESC、kind、id。source_token 固定原SKU/当前目录、库存/销售/退供、采购/收货/质量/退供共同流水与本店预留来源；后续页必须携带 expected_source，任何相关来源变化拒绝继续拼旧页。页面保留已读页和筛选，可从最新来源重读；退出清空窗口。

不新增业务表，schema39/159表保持。独立恢复后同一来源和数量投影、固定引用、快照前缀及 source_token 相同。原50任务287要求保持，43项具体交付可勾选，完整批次矩阵、扫码、仓位分配、调拨、盘点、成本和业务验收仍待。

开发验证：10项来源专项，涵盖实际与未知区分、六类关联、完整分页/同刻去重、跨店与当前身份、正向只读、不明参数拒绝、恢复投影一致、旧库存来源引用、原单预留和销售出库及当前目录变化；电脑手机筛选、原业务入口、实物核对、陈旧分页/重新读取与退出。全量764项、29组浏览器与159表恢复按版本交接记录实际结果。
