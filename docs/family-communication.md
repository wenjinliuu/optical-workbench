# 本人通知偏好与同意信息（V0.60）

对应 T08.02 / M16-F04。门店负责人或前台向指定、当前有效授权的监护人明确公开通知说明或同意信息说明，公开文本与内部依据分开。家长主动选择当前原说明，记录希望的联系渠道、服务提醒偏好，或提交同意说明调整意向。没有默认选项；“未知”“不希望提醒”分别保存，不作允许或批准。

员工独立核对回复不替换本人偏好，不调整原临床同意，不发送外部消息。正式同意、身份核验和专业业务沿原流程；这里没有代签或审批动作。家长姓名/电话也不自动成为联系渠道的已验证地址。工作台内服务通知和已读回执另接。

说明和意向均追加不可变版本。意向固定原说明 id，后续新说明不替换旧采用版本。新意向必须明确采用当前说明。撤回说明关闭该版本及所有更早版本和相应家长意向的访问；新公开不会恢复旧撤回资料，员工仍可读历史。最新通知偏好撤回显示已撤回，不自动采用更早偏好。说明撤回后，不把不可读的原偏好当作新的允许。

接口 `/api/family-communication/context/:customer` 为本店员工选取指定本人。`/api/family-communication/family|staff/:customer/:recipient` 返回说明及同源有界意向分页；`/information?kind=notification|consent` 读取有界说明历史；`/actions/:root` 读取固定意向及分页回复历史。员工 POST `/information` 公开或撤回，本人 POST `/actions` 提交，原 `/actions/:root` POST 追加本人撤回或员工核对回复。所有写入与审计、幂等保存同事务。

服务端核对门店/本人/当前授权、有效账号/待改密/会话以及源指纹。提交正文等待后重新核对身份；重复提交只保存一次，撤权或说明撤回拒绝旧缓存重放。数据库原生约束保护原身份、固定引用、连续版本/序列/时间、明确字段与不可覆盖；每个动作固定当时信息序列前缀，独立恢复能检查同刻原说明，不凭今天状态改旧记录。客户内部时间轴仅负责人/前台可读。

页面使用空白明确选择、来源变化保留本人填写及手工重新核对；关闭/退出清空对话框。家长采用异步内容前再核对来源，授权/公开说明撤回后的迟到内容不显示。桌面与手机共用同一事实。
