# 原标题命中范围三维矩阵计划 · V0.89

## 目标

在V0.88固定全部直接后续引用的账号状态×当前责任岗位×八状态完整矩阵之外，单独返回当前已采用原标题文字命中范围的同维3×4×8含零矩阵。两张矩阵必须明确区分，不能用当前页或状态、岗位、账号状态筛选后的列表反推。

## 边界

- 标题命中沿用既有参数化SQLite字面匹配，只读取固定后续原任务标题；不搜索说明正文、人员身份或其他字段。
- 标题矩阵只受当前已采用的原标题文字影响，不受已采用状态、岗位、账号状态、分页或当前页影响；96格总和等于该标题文字的完整命中数。
- 空标题文字时，标题矩阵与固定全量矩阵相同；无标题命中时仍返回完整96格零值。
- 单元格只采用既有标题文字，并明确设置现有账号状态、岗位和状态；不新增优先级、时限、代理、专业资格、临床、资金或扣次规则。
- 保留本人完成来源、固定引用、门店/员工权限、账号启停与责任变化失效、同源分页、独立恢复及退出隐私保护；无业务写入、表或迁移。

## 验证

- 单元测试覆盖完整键序、零值、标题命中总和、相同标题下三种筛选独立、无命中、105条分页和恢复一致性。
- 电脑/手机浏览器覆盖两张矩阵明确区分、192个单元格入口、105固定引用/103标题命中四页、准确标题矩阵快捷入口、草稿/采用隔离、迟到响应、原办理返回、重置/退出及无错误/横向溢出。
- 执行Node 24语法、专项与全量测试；以精确功能提交的GitHub Actions实际结果为最终证据。
