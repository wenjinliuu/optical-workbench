# 固定后续引用当前接收人账号可用状态 · V0.87

## 已实现范围

- 本人已办理完成原任务的固定直接后续引用增加当前接收人账号状态：已指派且账号有效为 `available`，已指派但账号停用为 `unavailable`，未指派为 `unknown`。
- 账号状态与原标题字面 `q`、当前实际责任岗位、八种当前原状态共同成为已采用筛选；四条件绑定同一查询、分页、详情及来源令牌。
- 返回完整三类账号状态计数、固定直接引用总数和当前四条件匹配量。完整计数在分页前计算并保留零值，不从当前页或命中页估算。
- 界面提供账号状态选择及完整计数快捷入口。填写中的文字、岗位、状态、账号状态草稿与已采用条件分离；普通刷新、追加和原任务办理返回不会暗中采用草稿。

## 数据与权限边界

- 只读取固定后续任务当前明确保存的 `assigned_user_id` 及其账号 `active` 事实；不从岗位、候选、历史负责人、专业资格或当前登录人推断账号可用。
- 未指派任务始终为“未指派未知”，不将候选岗位或创建人解释为可用账号。
- 账号启停、责任转交、候选或状态变化会改变来源令牌，旧续页、旧查询及旧详情证明均拒绝；父完成来源、固定后续引用和当时采用的更正版本不改写。
- 保持本人、本店和当前会话门禁；读取不增加业务写入，不授予资格，不生成代理、审批、提醒、通知、临床、资金或扣次规则。
