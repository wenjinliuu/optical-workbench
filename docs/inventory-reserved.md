# 原订单预留原件与仓位实际核对 · V0.47

固定一个原SKU预留事件和原订单行，人工明确匹配原收货原件身份、数量与仓位。它为下一步实际预留出库选批保存可核对依据，不再次预留、扣库存或付款，也不把多次观察相加为今天原批余量或独占分配。

原预留须仍有效，原SKU/单位和原收货固定商品版本一致、匹配数量已入库。实际观察已发生UTC不得早于原预留与实际入库。本次数量同时受该原预留行减已实际出库、当前实际reserved和原收货减原实际退供、明确已售及原质量保护的上限约束。另一箱同SKU库存不能让已售或受保护原件重新出现在原单保管中。

根固定原预留/行/收货，旧原资料与当时stock/outbound/return/receiving/quality/batch/reservation前缀保留。新现场观察明确采用当前来源，明确撤回解释不释放SKU预留；原预留释放或后来另预留后旧记录可读，原根不能改作另一预留。观察本身不证明当前完整批次余额，已有reserved出库仍保留原批未记录，下一V0.48显式采用原单原批依据。
