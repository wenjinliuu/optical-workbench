# 本人完成记录的固定后续引用 · V0.83

继续T03.03。本人实际完成记录增加后续展开入口，只列该原完成任务直接保存的task_followups引用及其当前任务责任/状态，不把下游的下游或其他任务自动并入。原完成操作人、原任务/客户/门店由服务端当前会话绑定；曾分派或接收不授予此入口。

GET /api/my-work/completed/:id/followups及其/authorization只读返回薄元信息：固定原完成哈希、当时采用的说明更正版本/保存时间，以及当前原任务修订、责任人/岗位、指派/执行/生命周期状态。完成、交接、专业、资金及人事正文不进入投影。原完成task_source_proof原样复用，固定引用版本不会继承后来更正。

expected_parent_source为列表采用的完整来源指纹。分页/原详情证明另绑定源令牌，涵盖全部固定引用及其当前责任/状态、当前角色和完成任务的小来源证明；当前状态/目标岗位/原说明更正/新链接变化拒绝旧证明。完整数量不从30项估算，稳定原保存时间/任务编号排序支持105以上分页；只接受明确分页/证明，不接受员工/门店选择。

原详情办理前后均重新核对本人完成入口和后续来源，原操作成功刷新本人已应用条件；清除/退出/改岗和迟到响应不得恢复嵌套私有内容。卡片与紧凑布局保留同一内容和动作，原文字按纯文本。无新表迁移、业务写入、认领/接收/执行自动化或正式规则。

8项专项覆盖权限和薄元信息、固定版本/当前状态区分、105完整引用分页/零写、原接收/移交/取消及旧证明拒绝、原更正和新引用失效、严格字段与当前角色、原引用/当前状态独立恢复。电脑手机覆盖实际原入口、固定与当前更正版本、紧凑/卡片、纯文本、手机原接收后刷新和退出迟到清空。全量精确源CI与双处回执见progress.json/progress-sync.json；原50任务/287需求及整体验收保留。
