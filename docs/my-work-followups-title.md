# 固定后续引用的原标题文字筛选 · V0.86

继续T03.03。只对当前员工实际完成原任务的固定直接后续引用、已允许返回的原任务标题作字面包含匹配，与当前实际责任岗位和八状态交叉筛选。没有检索任务说明、完成产出、客户姓名、任务编号、临床、资金或权益正文；没有新增业务表、迁移、写操作或正式规则。

列表与证明接口接受同一单值q，省略/空字符串表示不限，最多120个UTF-16代码单元，与现有本人工作台边界一致；NUL及重复参数拒绝。使用参数化SQLite instr(lower(title),lower(q))，英文ASCII忽略大小写，其他字符按原样字面匹配；百分号、下划线、引号和括号均不作为通配符或表达式，不修剪/改写已采用文字。标题沿用原任务不可变约束。

filter包含q、responsibility_role、task_state；source_token绑定这三个已采用条件、父完成来源、当前员工/门店/角色及全部固定后续当前事实。即使命中相同的不同文字，也不能跨条件复用续页或证明。原标题匹配在分页前完成，total/state_counts/role_counts/state_role_counts仍表示完整固定直接引用事实，matched_total表示三个条件交集；标题匹配计算字段不进入薄投影。

界面显示已采用原标题文字和当前岗位/状态，未查询填写独立。普通刷新、追加、岗位/状态完整计数快捷入口沿用已采用文字与另一已采用条件；独立填写保留，只有查询或明确重置采用新值。原任务办理后重新打开同一父来源，采用组合与独立草稿都保持；任务离开已采用组合时移出匹配，固定引用/完成哈希/采用更正版本不改写。记忆只在当前会话，退出/撤权清空文字输入、组合记忆、私有行/计数/摘要；迟到旧页/查询/详情不能恢复。
