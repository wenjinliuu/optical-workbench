# 本人完成记录四入口来源一致性

V0.82 继续 T03.03，只读核对同一原通用任务在四个既有入口中的来源：本人已办理记录、关联任务链、八列任务看板和客户时间轴。没有新增任务、今日、优先级、时限、通知或专业规则。

## 统一来源证明

有完成记录的任务由 `taskSourceProof` 投影同一最小证明：原任务、客户、门店、完成前任务修订、条件/依据版本、完成快照哈希、实际完成时间与操作人、当前说明更正版本，以及全部后续任务的固定来源引用。以上字段生成 SHA-256 来源指纹。

- 本人已办理范围返回 `task_source_proof`，只包含版本和引用证明，不返回完成正文、专业内容或资金资料。
- 任务详情、八列看板和任务链的已完成节点返回同一证明。
- 客户时间轴的完成、更正及后续事件返回同一原完成任务证明；后续事件证明指向其 `parent_task_id`，不把后续任务误作原任务。
- 后续任务固定引用原完成快照哈希及采用的说明更正版本，证明中按保存时间和任务编号稳定排序。

原表继续不可变；本切片无新表、迁移或写入。说明更正或新后续记录会生成新指纹，并使旧本人工作台来源令牌失效，要求明确刷新。

## 验证边界

`test/my-work.test.mjs` 核对四个 API 投影逐字段完全一致、后续固定哈希正确、指纹稳定且不包含完成/交接正文。`scripts/my-work-blockers-browser-check.mjs` 核对桌面和手机的本人完成卡片、任务办理、任务链、八列看板与客户时间轴显示同一短指纹，并保留退出后迟到响应清空、无运行时错误和无横向溢出。

本能力仅证明既有保存来源的一致性，不表示整项任务、专业结论或客户服务已验收。
