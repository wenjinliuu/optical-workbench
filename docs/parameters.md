# 配镜参数交接 · V0.26

本切片保存人工填写的加工交接值及来源，不提供专业测量标准、自动诊断或正式处方批准。R02/R10的真实表单、资质和专业重做决策继续待确认。原单、实收退款、库存、旧件保管和重做新单分别保持。

负责人、前台和专业开发角色可按当前订单实物行保存1–100项明确名称和值，单位未知留空，条件明确填写或留空；明确记录员工/外部资料转录/客户自报来源及说明。不得关联服务行或其他客户资料。最多各10个固定资料版本和附件，资料后来修订不覆盖原引用；撤销附件后不能提交、核对或继续受保护执行。

状态为交接草稿→提交→交接已核对或退回补充；仅专业开发角色可明确核对或退回，必须填写说明和依据。退回可再次提交，值和来源仍不可变；改值另存新版本。旧订单版本参数不用于新订单版本。

第一次开工固定当时已核对参数；没有交接记录的早期执行保留“未登记”，不补造参数。当前交接未核对或已开工后版本变化会阻止开工、完成、所有质检/返工/签收动作。当前专业开发角色明确选择“按原参数继续”或“暂缓”；继续保留第一开工版本或原未知来源，不自动将新参数用于旧工单，不自动生成返工、换货、费用或退款。新版本再次要求核对。收货、备料和交期登记独立；已经签收的实际库存出库不作为本切片的参数门禁，不等于召回或临床放行。

所有写入包含CSRF、幂等键、原订单/参数流水和对象当前版本；加工、质检受保护动作增加expected_parameter_sequence和expected_parameter_review_revision，陈旧请求409拒绝。业务、原执行引用和审计同事务回滚。前端重读冲突保留手工值、来源选择和说明，明确核对后重新提交；退出登录阻止延迟响应重建数据。
