# V0.81 本人已办理完成的原任务记录

继续 T03.03。本人工作台新增“本人已办理完成的原任务”独立只读范围；它不并入当前十四类责任，不并入岗位候选，也不改变原员工责任总量。

## 原事实与范围

- 只采用 `task_completions.completed_by` 作为本人实际完成依据，并同时核对原任务门店与当前会话门店；曾被指派、打开、认领、接收或开始均不视为完成。
- 每条记录固定原任务 ID、原任务修订、原完成时间、条件版本、依据版本与完成快照摘要；列表不返回完成产出正文、专业正文、资金正文或人事资料。
- 只读显示当前说明更正版本和后续任务数量。更正与后续仍是不可变原记录，详情继续沿原任务权限读取，不在本人工作台复制或改写正文。
- 当前责任、同岗位候选和本人已办理完成三类范围分别查询、计数与分页；完成记录仅支持全部或通用岗位任务，不套用当前任务阻塞/接收/暂停/执行状态。

## 查询、证明与多端

- 文字匹配原任务标题、原客户名或原任务 ID；日期状态与区间使用原 `completed_at` 的 UTC 日期，排序使用原完成时间及原任务 ID 稳定排列。
- 来源证明绑定当前员工、角色、门店、完整筛选、原完成记录、说明更正和后续引用前缀；新增更正、后续任务、角色或门店变化会拒绝旧证明。
- 完整分页使用同一来源令牌，105 条以上记录不缩减为当前页；读取与证明均零写。
- 卡片和紧凑列表展示同一原任务、固定版本和只读入口；电脑与手机均明确区分当前责任、岗位候选和已办理记录。退出、撤权或迟到响应继续清空私有列表及证明。

## 保留边界

该入口只说明“当前登录员工提交过这一条通用任务完成记录”，不代表相关服务周期、专业检查、处方、报告、资金、权益或整项业务已经完成，也不补造任何完成事实。正式专业许可、临床表单、财务口径与整体验收仍待真实依据。
