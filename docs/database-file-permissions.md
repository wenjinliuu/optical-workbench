# 新建活动数据库文件权限

V0.96 仅收紧新建本地活动数据库的文件系统权限，不改变既有数据库、正式部署架构或数据保留规则。

- 新建父目录由运行进程以 `0700` 创建；已经存在的目录权限保持不变。
- 数据库路径通过排他创建原子保留，新文件模式为 `0600`；并发进程只有一个会把该路径识别为新文件。
- SQLite 在数据库文件为 `0600` 时创建的 WAL/SHM 旁路文件继承私有权限。本轮在 Linux、`umask 022` 下实际核对数据库、WAL 与 SHM 均为 `0600`。
- 已存在数据库的内容和权限不被本步骤重写；`:memory:` 不触碰文件系统。
- 本步骤不声称解决同一全新数据库的并发迁移锁。该问题保留为下一独立切片，需核对等待设置顺序、迁移内重查和失败清理。

验证覆盖新建库、既有库、内存库、WAL/SHM、并发路径保留、全量迁移与恢复回归；测试只使用虚构记录，不输出数据库内容或凭据。
