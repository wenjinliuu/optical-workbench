# V0.55 家庭服务与权益发布

T08.01第一切片。负责人从固定客户选择当前有效授权的指定监护人，填写明确对外说明，并逐项选择0到20份该客户的原权益记录。保存操作就是明确发布；未发布的内部权益与备注不会进入家庭页面。当前本地角色不替代正式身份核验、监护资格或报告审批。

家庭只能读取指定给本人且当前授权有效的发布内容，以及原流程已向本人发布的家庭练习。页面重新验证授权和发布来源后才采用返回内容；撤销授权、撤回发布或退出登录时，不采用迟到的旧响应。员工的内部发布依据、下一步、原购买来源、金额和原权益规则说明不对家庭显示。没有自动通知或消息发送。

## 固定原来源

family_share_roots固定客户、接收人和门店，FS编号连续。版本固定发布时接收人最小快照、原权益客户流水前缀、显式标题与对外说明。items固定原权益ID、修订、原套餐版本及名称，分别显示购买/赠送登记与原误录冲销的次数或期间记录数量。显示的是发布时登记，不推断剩余可用次数、消耗、效期、适用资格、实际到账、扣次或退款。

原权益后来纠正不自动替换旧公开说明。发布新版本必须重新采用当前授权和原权益；输入保留，员工手动核对后再保存。新版表单为空白，不复制旧说明或自动选择权益。接收人和客户不能在同一发布根上更换，应另建明确发布记录。

撤回仅关闭本人访问，保留员工可核对的全部原发布和撤回历史。撤回后重新发布新版本不会恢复本人对先前被撤回版本的访问。原授权撤销后员工仍可执行负向撤回，不要求伪造有效授权。

## API

- 员工GET /api/family-progress/customers/:customer/options：当前有效接收人、原权益分页及来源令牌。
- 员工GET /api/family-progress/customers/:customer：本客户公开说明的历史根分页。
- 员工GET /api/family-progress/:id：当前或数值旧版本与有界原事件历史。
- 员工POST /api/family-progress、/:id/versions、/:id/events：明确发布、新版、明确撤回；负责人/本店，提交正文后重新核对身份/会话，事务内复查当前原来源，审计与幂等结果原子保存。
- 家庭GET /api/family-progress/family：当前授权客户。
- 家庭GET /api/family-progress/family/:customer：向本人发布的最小服务权益内容及已有已发布家庭练习，有界分页。
- 家庭GET /api/family-progress/family/:customer/publications/:id：固定原公开版本，逐次核对当前授权/接收人/撤回截止版本。
- GET /family-authorization、/family/:customer/authorization：采用响应前重新验证授权，客户证明可同时检查expected_source防止撤回后的迟到内容。

分页默认30，最大100；后页必须匹配expected_source，未知/重复查询参数拒绝。权益选项完整分页读取，明确最多选择20份。公开内容分页与练习分页使用相同offset，各自保留next_offset，不因另一流较短遗漏后页。管理入口与家庭入口各自限制角色；其他监护人即使同客户已获查看授权，也不能读取未指定给本人的发布。
