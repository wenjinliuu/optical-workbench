# 家庭原接口脱敏运行诊断 · V0.91

T01.04 / N07 的运行保障修复：家庭发布与进度、申请与回复、时段选择、预约办理、请假调课、偏好说明、通知与原版回执、申请通知追溯、练习与复评九类现有接口，此前发生故障时都显示为未知请求。现在逐一按实际 handler 契约登记固定诊断模板，运行面板显示九个明确区域。

模板只用于诊断，不参与路由分派、权限或业务写入。客户、监护人、申请、预约、通知、练习、报告、原版本等路径片段全部替换为固定占位模板；查询、来源证明、正文、Cookie、CSRF 和数据库错误不进入日志。原申请反向通知与授权核对 handler 固定归入既有“申请通知追溯”，不会复制申请编号。多余路径段、非法形状和未登记接口继续匿名为 `/api/unknown`，不能从调用者输入拼接标签。

本店负责人读取本店运行窗口、200 请求窗口、最近 20 个故障、故障编号关联及中断 499 只计一次的既有边界保持。家庭原接口的员工/监护权限、固定来源、不可变版本和恢复格式没有改变；schema60 无新表、迁移或业务记录，也不构成业务验收、正式监控或真实送达能力。
