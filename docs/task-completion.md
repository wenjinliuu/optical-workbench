# 通用任务核对依据与完成条件

状态：V0.12已实现通用核对条件版本、依据草稿及只读校验。尚无完成接口/完成状态或自动下游任务；原专业职责、专业确认/审批及业务完成规则仍单独落实。

负责人/前台在任务内明确通用核对范围、资料/附件要求并保存条件新版本。scope固定generic_record_review、核对说明必填；不根据标题或演示场景猜测条件，旧任务无配置。条件变更保留旧版，已有依据仍引用原版并提示重新核对。

当前有效岗位的任务接收人本人，已接收且未取消时可保存依据草稿新版本；暂停或阻塞允许留待补。说明、来源、保存原因与员工/时间明确；资料引用document_versions.id及附件id限定同一客户。可选原V1，即使已有V2，后来资料修订不改写旧引用。缺项草稿可继续补，新版本保留原条件、任务修订和引用。

校验可直接检查未保存输入，不产生版本/事件/审计/重试记录。当前本人/岗位、接收、运行、正常无异常、当前条件/任务修订、说明、必需资料/附件和附件可访问逐项提示。record_ready仅表示这组通用核对项齐备，completion_enabled始终false；草稿或检查通过均不结束任务、周期/到店，不发布报告、收退款、扣次、出入库存或生成下一任务。

界面提供条件/依据历史、已撤销附件提示和重读保留填写/选择；条件或草稿并发变更须重新核对。历史责任/执行来自保存时的task_events快照。备份/恢复保留四表并核对连续版本、固定引用清单、外键及附件；时间轴包含各次实际保存，不用当前状态替代过去状态。

| 下一切片 | 实施方向 | 仍需明确 |
| --- | --- | --- |
| 通用核对明确提交 | 复用保存的条件/依据与实时校验；固定适用版本、执行身份和产出 | 提交与通用完成的独立语义、撤销/更正流程；不替代专业确认 |
| 专业完成 | 绑定专业表单及确认/审批版本 | 实字段/单位/缺测原因、职责/资质、发布与业务规则来源 |
| 下游推进 | 明确触发与模板，事务/幂等保存关联 | 串并行/汇合、循环、取消恢复和资金/权益/库存条件 |
| 工作日历与时限 | 当前任务责任及实际动作时间接入 | 营业日历、截止日、通知渠道和升级对象 |
