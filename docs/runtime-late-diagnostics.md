# 后期模块脱敏运行诊断

V0.93 仅依据现有 API handler 的固定路径形状，为运行故障补齐四个匿名区域标签：

- `专业随访与转介`：专项服务、照护/连续性/追溯、转介、联系与纵向计划；
- `采购收货与退供`：供应商、采购、收货、质量、退供与额外交接；
- `库存实物与出库`：实物核对、固定预留、批次来源与出库签收；
- `费用与渠道核对`：费用记录、原收退款核对与人工渠道核对。

诊断标签固定为 `/api/professional/:scope`、`/api/procurement/:scope`、`/api/inventory-trace/:scope` 和 `/api/financial-review/:scope`。路由中的客户、订单、批次、费用、原版本、名单位置和查询值均不复制到日志；合法 handler 之外的多余片段继续记录为 `/api/unknown`。

本切片不增加接口、不改变 handler 顺序、权限、门店隔离、不可变版本或业务写入，也不解释临床、财务、扣次或退款规则。运行窗口仍为每店最近 200 个请求和 20 个故障，中断请求只记一次；日志回调失败不影响业务响应。

验证覆盖四组代表入口、全部审计 handler 家族、畸形扩展、跨店隔离、窗口上限、中断计数、中文显示与电脑/手机错误面板。浏览器只使用虚构标识，并断言页面不出现这些标识。
