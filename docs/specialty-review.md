# V0.37 原镜片复查与异常处理

T06.04 / W4-N5 的开发切片。固定实际专项签收原产品、原评估、批准、数量、批号和当时护理版本；复查、不适、损坏、遗失和其他异常分别明确来源。未签收的产品不补造佩戴反馈。客户原反馈、实际检查或无法测、眼别与条件未知/不可比保留，不生成临床指标、诊断、方法或默认复查频率。

实际反馈版本与专业意见分离。接待可转录实际原来源；当前专项专业责任人明确确认本版的继续、调整、暂停、停用、转介或暂不能判断，并保存实际处理时间、处置意见和下一步。继续须原评估同意及订片来源有效。调整或转介意见不自动改变参数、产生订单、预约或外院结果。明确暂停/停用则在同一事务中追加原专项状态事件和对应复查意见，两边审计失败一起回滚；之后的新业务执行仍受原专项门禁保护，不自动退款或结束服务周期。

新的实际反馈版本返回待专业确认，旧意见仍绑定旧版。原指导材料后来更正或同意撤回不替换旧签收来源和专业意见。结束本条复查须已有本版专业意见；取消待处理安排另行记录，不能标成已完成专业检查。明确停用后可保存新的原产品归档事实，不恢复原专项；新业务需求仍另行办理。

复用已有同客户、本店的实际长期检查版本和已确认外院原版本，来源更正后新采纳要求当前明确版本。可以关联既有复查计划、转介版本和实际已记录的服务联系；关联不表示已到店、已收到报告或已读回执，不发送真实消息。下一复查日期人工明确填写，可留尚未安排，逾期仅由指定 UTC 日期派生；后续状态仍由各原业务责任人办理。

四表 specialty_reviews / review_versions / review_events / review_links 加入 schema34、客户时间轴和独立恢复。专业意见捕获当时专项、订片、参数、长期检查和外院序列，暂停/停用固定对应的临床效果事件。复查与后续关联共用本店连续序列，能区分同毫秒的前后反馈版本；恢复核对原签收、护理、批号、专业责任、明确效果及原后续版本，不用当前状态替换旧事实。内部资料按门店、角色、会话及 CSRF 控制，来源和审计/幂等同事务核对。

“接触镜 / OK 镜专项”增加复查与异常队列、处理和反馈类别筛选；原单产品追溯进入实际产品复查。电脑、390px 手机可以追加反馈、保存明确专业意见、查看旧意见、原专项状态和已有后续关联。原实际检查、外院和护理入口带固定材料版本；冲突保留填写并要求从明确最新来源重新开始，退出后迟到响应不显示内部数据。

四个保存的虚构阶段：不适待核对、原意见明确调整、镜片遗失且无法测、原异常专业明确停用。停用示例单独新增专项评估/同意和原单，不更改既有临床或商业事实；重复初始化保留人工记录。25 项专项检查覆盖意见分离、继续来源、暂停停用原效果/回滚、原材料及跨模块来源变化、实际后续关联、门店/专业责任及待请求体移交、同毫秒替换、四表恢复、非空 schema33 升级和重复虚构阶段。

完整更换重订、原镜片退回与质量责任、长期归档仍是下一切片；真实资质、临床表单、方法、频率与费用/退款规则依实际来源逐项办理。整项业务验收保持待完成。
