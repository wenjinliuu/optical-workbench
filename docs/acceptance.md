# 页面、状态与验收草案

## 基础页面

| 页面 | 岗位 | 本轮状态 |
| --- | --- | --- |
| 登录 | 全部开发身份 | 空、错误密码、限速、登录中、成功、会话撤销 |
| 客户列表与详情 | 授权员工/家长 | 联合搜索、无结果、API失败；选中卡片不改变业务状态 |
| 建档对话框 | 负责人/前台 | 必填/有效生日/重复提示/保存中/失败重试/已保存 |
| 周期草稿 | 负责人/前台/专业人员 | 客户上下文固定，多个周期独立；只有 draft |
| 审计 | 负责人 | 当前门店列表、刷新、空、越权拒绝 |
| 开发范围 | 已登录用户 | P00/P01部分完成、未验收与阻塞说明 |

完整的工作台、流程图、看板、检查、报告、排课、训练、权益、零售、库存、家长发布、筛查、统计与配置页面仍按原需求追踪，后续扩展此表。

周期状态正式设计：draft → active（具备职责人员确认）→ paused（有理由）→ active（确认恢复）→ ended（结束原因及后续安排）；当前仅实现创建 draft，其余迁移拒绝（无接口）。保存客户不产生检查或任务，保存周期不产生专业意见、订单和权益。

## 七条业务流程的出口案例（全部待业务实现）

| 流程 | 正常案例 | 异常/恢复案例 | 主要阶段 |
| --- | --- | --- | --- |
| 配镜交付 | 档案→确认处方快照→订单→加工→合格质检→签收 | 缺货分别阻塞；不合格返工；分批交付核数量；退款不终止长期计划 | P02/P03/P04 |
| 儿童训练 | 评估→版本计划→排课→实际执行→按规则一次扣次→复评 | 缺席/中止按规则；资源冲突；扣次失败不得显示全部成功；冲销关联原流水 | P05 |
| 长期随访 | 到期联系→预约→实际复查→专业确认下一轮 | 失联/改期/无法测/外院来源；结果不覆盖本店实测；联系发出不算到店 | P06 |
| 接触镜/OK镜 | 授权评估→参数订片→批号验收→护理交付→复查 | 资质不符/参数变更/不适/停止；追溯且不自动做专业决定 | P06 |
| 采购库存 | 审批→在途→分批验收→可售→预留→交付 | 重复入库、超卖、隔离退货、调拨差异和盘亏审批 | P04/P07 |
| 团体筛查 | 授权名单→匹配→检查→确认→个人发布→复查跟进 | 同名重复不覆盖；缺授权；设备未知不补零；汇总/个人访问分开 | P08 |
| 售后返工 | 原单关联→建议→审批→执行→质检/资金核对→结案 | 退款渠道失败、重复返工、跨店、同批次质量追溯；未解决不静默结案 | P04 |
